Architecture Vue 3 FastAPI In-Memory

Factory Inventory Management System

Full-stack demo — Vue 3 frontend · Python FastAPI backend · JSON mock data · No database

Tech Stack

Frontend
Vue 3
Composition API + reactive refs + computed. No Vuex — shared state via composables.
Router
Vue Router 4
6 client-side routes. History mode. Nested modal layers.
HTTP Client
Axios
Centralized api.js. URLSearchParams for filter query strings.
Build Tool
Vite 5
HMR dev server on port 3000. @vitejs/plugin-vue.
Backend
FastAPI
21 REST endpoints. Pydantic validation on all responses. CORS wildcard for dev.
ASGI Server
Uvicorn
Runs on port 8001. Auto-reload in dev mode.
Validation
Pydantic v2
Type-safe response models for all 21 endpoints.
Data Layer
JSON Files
7 static JSON files. Loaded into memory at startup. No persistence.
Package Manager
uv
Fast Python package manager. Manages virtualenv and deps via pyproject.toml.

Shared State — Composables

useFilters.js

Singleton global filter state shared across all 7 views
  • selectedPeriod (month / quarter)
  • selectedLocation (warehouse)
  • selectedCategory
  • selectedStatus (order status)
  • getCurrentFilters() → API params
  • All views watch these refs

useAuth.js

Mock user session with task management
  • currentUser (name, role, avatar)
  • tasks[] with priority / status
  • createTask(), deleteTask(), toggleTask()
  • Language-aware user fields
  • Logout stub

useI18n.js

EN / JA localization with auto currency mapping
  • locale ref (EN / JA)
  • t(key) translation function
  • Persisted to localStorage
  • Auto currency: USD / JPY
  • translateProductName(), translateWarehouse()
  • English fallback for missing keys

Key Patterns & Constraints

Frontend Reactivity

  • → Raw data in ref()
  • → Derived values in computed()
  • → API calls triggered by watch()
  • ! v-for keys: use sku/id, not index
  • ! Validate dates before .getMonth()

Backend Filtering

  • → 'all' sentinel skips that filter
  • → Filters applied sequentially
  • → Never mutate global data lists
  • ! Inventory has no month dimension
  • ! Update Pydantic when JSON changes

Revenue Goals

  • → Single month: $800K target
  • → Full year (all months): $9.6M
  • → Mock data is demo-only
  • → No DB — restart resets state
  • → POs persist only in-session
